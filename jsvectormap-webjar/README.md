# jsVectorMap WebJar (de.l9g.webjars)

jsVectorMap 1.5.3 (CSS + JS + world map data) packaged as a WebJar under the
`de.l9g.webjars` namespace. Resources are served at
`/webjars/jsvectormap/1.5.3/…`.

## Install locally

```bash
mvn install
```

## Use

```xml
<dependency>
    <groupId>de.l9g.webjars</groupId>
    <artifactId>jsvectormap</artifactId>
    <version>1.5.3</version>
</dependency>
```

```html
<link rel="stylesheet" href="/webjars/jsvectormap/1.5.3/jsvectormap.min.css"/>
<script src="/webjars/jsvectormap/1.5.3/jsvectormap.min.js"></script>
<script src="/webjars/jsvectormap/1.5.3/maps/world.js"></script>
```
